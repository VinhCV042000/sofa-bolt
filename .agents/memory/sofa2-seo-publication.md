---
name: Sofa2 SEO publication semantics
description: How page quality labels, publication state, redirects, and sitemap inclusion relate.
---

For page SEO records, treat the SEO quality status as an audit label rather than a publish gate. The explicit published state controls whether page metadata is applied; sitemap inclusion additionally requires indexability, sitemap inclusion, and no redirect.

**Why:** A page can remain useful and live while its SEO checklist still needs improvement. Using the quality label as publication state would unintentionally remove valid routes from search.

**How to apply:** Keep the admin publication toggle, public metadata response, redirect handling, and sitemap builder aligned when changing Sofa2 SEO behavior.
